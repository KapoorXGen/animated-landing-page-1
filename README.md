# Animated Landing Page 1

An animation-driven landing page built using **HTML, CSS, JavaScript, and GSAP**.  
This project focuses on **high-quality motion design**, **Flip animations**, and **timeline-based UI transitions**, inspired by modern creative agency websites.

---

## Project Overview

This project demonstrates:

- Advanced **GSAP-based animations**
- **Image Flip transitions** using GSAP Flip plugin
- **Line-by-line text reveal** animations using SplitText
- Animated **counter loader**
- Smooth UI reveal animations (navigation, sidebar, dividers, typography)

The primary goal of this project is to showcase **frontend animation engineering skills** along with **clean and incremental Git version control**.

---

## What Happens in This Project

### 1. Loader & Initial Animation

- A numeric counter animates on page load
- Background expands vertically
- Images scale in sequentially

### 2. Image Flip Transition

- Images transition from one layout state to another
- GSAP Flip handles layout and position changes
- Additional scale animations add depth and motion

### 3. Text Reveal Animation

- Headings, paragraphs, and links are split into lines
- Each line animates upward smoothly
- Creates a premium typography animation effect

### 4. UI Reveal

- Sidebar divider animates vertically
- Navigation and content dividers animate horizontally
- Logo and text reveal after layout stabilization

## Tech Stack

- **HTML5** – Semantic markup
- **CSS3** – Layout, styling, responsiveness
- **JavaScript (ES Modules)** – Animation logic
- **GSAP** – Animation engine
- **GSAP Flip Plugin** – Layout transition animations
- **GSAP SplitText Plugin** – Text reveal animations
- **Node.js & npm** – Dependency management
- **Git & GitHub** – Version control

## How to Run the Project Locally

### Step 1: Clone the Repository

```bash
git clone https://github.com/KapoorXGen/animated-landing-page-1.git
```
### Step 2: Install Dependencies

Make sure Node.js is installed on your system.
> npm install

### Step 3: Start the Development Server

> npm run dev
